How access works here

There are exactly two accounts and they cannot be created or deleted from this screen — that is deliberate, so the portal can never end up with nobody able to manage it.

  • The Super Admin manages the Admin account: rename, disable, reset password, sign out devices.
  • Nobody can change their own role or status here, including the Super Admin.
  • The last active Super Admin cannot be demoted or disabled.
  • Disabling an account ends its live sessions immediately.
  • Everyone changes their own password on the Change my password page.
