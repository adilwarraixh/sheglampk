Things that are not editable here

Deliberately kept out of the portal, because a wrong value would take the shop down and there is no undo from a web form:

  • Database connection — set as an environment variable on the host.
  • Payment method — the shop is cash on delivery only, enforced server-side.
  • Admin roles and permissions — see Admin Account.
  • Domain and hosting — managed at your DNS and hosting provider.
